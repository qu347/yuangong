# ADR-0002：第一阶段只支持 Windows 与 Android

- 状态：已接受
- 日期：2026-08-14

## 背景

企业当前客户端范围只有 Windows 电脑与 Android 手机，未来可能增加 iOS。

## 决定

Flutter 工程只生成和维护 `android/` 与 `windows/`。业务代码保持平台无关，平台能力通过服务接口封装。iOS、Web、macOS 与 Linux 不进入当前工程或 CI。

## 结果

- 测试与构建范围更小，适合两人团队。
- 未来增加 iOS 时可复用业务层，但必须单独评估安全存储、分发与签名。
- 当前不得为未来平台提前创建目录或复杂抽象。
